## Kannada and Japanese

- [Japanese as a case study](../kannaDa/grammar/tense-aspect-mood#case-study-japanese), from *Tense, Aspect, Mood: DNS Bhat vs Chomsky*. It sets Kannada and Japanese verbs side by side:
  - the same past/non-past split with no grammatical future
  - the same three converbs: ಮಾಡಿ / ಮಾಡುತ್ತ / ಮಾಡಲು beside -te / -nagara / -ni
  - tensed relative clauses, vector verbs, and modality expressed through auxiliaries
  - where the two languages differ, and how Bhat's tense-prominence model fits Japanese
- [Bhat on kana and Kannada letters](../kannaDa/dnsbhat/29-kannaDa-vyAkaraNa-yAke-bEku/book/kn/ch2#sub-2-3-2), from *ಕನ್ನಡ ವ್ಯಾಕರಣ ಯಾಕೆ ಬೇಕು?* §2.3.2. Bhat calls katakana a syllabic script (ಉಲಿಕಂತೆಯ ಲಿಪಿ), where each sign stands for a whole syllable. Kannada letters also mark whole syllables, but the consonant part and the vowel part can be told apart, so Bhat calls Kannada a sound script (ಉಲಿಲಿಪಿ), like the Roman alphabet. Children, he notes, learn to read syllabic scripts more easily.
