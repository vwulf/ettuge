# An Introduction to Functional Programming Through Lambda Calculus

> Greg Michaelson · Addison-Wesley, 1988 (author’s electronic edition) · [the PDF in Drive](https://drive.google.com/file/d/1j0lUd0GSneAMx0DWGqHoW78KSM_Wu_sN/view)

Chapters only; answers to exercises (PDF pp. 216–241) are not broken down. Summaries are in our own words; the text stays in the PDF.

## The book in one paragraph

A gentle course that teaches functional programming by building it inside the pure λ-calculus. Starting from nothing but abstraction and application, Michaelson encodes booleans, conditionals, natural numbers, recursion via a fixed-point combinator, typed values, lists, strings, records and trees, introducing friendlier notation only after each construction is understood. He then compares evaluation strategies (normal order, applicative order, lazy evaluation) and finally shows how the same ideas look in two real languages, Standard ML and LISP.

**Contents**

1. [1. Introduction](ch1): Names and values, why execution order matters less in functional languages, and the mathematical and historical roots of functional programming.
2. [2. Lambda Calculus](ch2): Pure λ-calculus: expressions, β-reduction, and building functions such as identity, application and pairs.
3. [3. Conditions, Booleans and Integers](ch3): Booleans, conditionals and natural numbers encoded as λ-terms, with simplified notation introduced along the way.
4. [4. Recursion and Arithmetic](ch4): Recursion through a fixed-point combinator, and arithmetic defined recursively on encoded numbers.
5. [5. Types](ch5): Adding run-time type checking to the encodings so that ill-typed operations can be detected.
6. [6. Lists and Strings](ch6): Lists and strings built from pairs, with list functions, mapping and searching.
7. [7. Composite Values and Trees](ch7): Records, tuples, binary trees and the functions over them, written in the book’s notation.
8. [8. Evaluation](ch8): Normal-order versus applicative-order reduction, lazy evaluation, and their consequences.
9. [9. Functional Programming in Standard ML](ch9): The same ideas in Standard ML: types, pattern matching, lists, higher-order functions and type inference.
10. [10. Functional Programming and LISP](ch10): The same ideas in LISP: S-expressions, list processing, and LISP’s functional subset.
