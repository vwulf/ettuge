# ಸೊಲ್ಲು ಕಟ್ಟುವ ಕೂಟ — Word Coining Sessions

*Coining native Dravidian Kannada words using Dr. D.N. Shankara Bhat's Ellara methodology.*

These sessions work through English, Sanskrit-loan, and borrowed terms — replacing them with native Dravidian coinages following the approach DNS Bhat used to produce words like ಎಲ್ಲರಾಳ್ವಿಕೆ (democracy), ಉಸಿರಿಯರಿಮೆ (biology), and ಗೆಂಟುತೋರ್ಪುಕ (telescope).

---

## Sessions

| Session | Source | Key coinages |
|---------|--------|-------------|
| [Newspaper Challenge](newspaper-challenge) | Kannada newspaper column (ಅಂಕಣ) | nodal → ಗಂಟಿನ, squad → ಕಿರುತಂಡ, template → ಅಚ್ಚುಕ, day names (ನಾಳು system), computing (ಮಿನ್nnU-) |
| [Karate & Kobudō](karate-kobudo) | Okinawan karate and kobudō terms | karate → ಬರಿಗೈಕಾಳಗ, kata → ನಡೆಅಚ್ಚು, sai → ಮುರ್ಮೊನೆ, tonfa → ಅಡ್ಡಹಿಡಿಕೋಲ್, stance → ಇರ್ಪು |
| [Botany](botany) | Parts of a flower, checked against a native diagram from Bhat | stamen → ಗಂಡುದಳ, carpel → ಹೆಣ್ಣುದಳ, ovary → ಮೊಟ್ಟೆಗೂಡು; ಕುರ್ಚಿ may be Dravidian |
| [Latin Legal Phrases](latin-legal) | Latin legal phrases against a vetted list | quid pro quo → ಕೊಡುಕೊಳೆ, pro bono → ಬಿಟ್ಟಿಕೆಲಸ, ad hoc → ಅದದಕ್ಕೆ |
| [Maths — ಎ-ಎಣಿಕೆ](maths) | Elementary functions around the EML operator | ಏ (exp), ಅ (ln), ಎ (eml), ಇ (i), sin → ನೇರಪಾಲು, π → ಸುತ್ತುಪಾಲು |
| [Śrī Rudram & Ritual Terms](rudram-ritual) | Namakam, opening verse | Rudra → ಗುಡುಗ, namaḥ → ಬಾಗುವೆ, priest → ತಮ್ಮಡಿ (Bhat), portfolio → ಕೆಲಸಕಟ್ಟು |
| [Physics & Grammar Terms](physics-grammar) | Newtonian mechanics, dimensions, tense–aspect–mood | force → ಒತ್ತಿಗೆ, mass → ಅಡಕ, 3D → ಮುರ್ಹರವು, aspect → ಎಸಕನೋಟ, mood → ಒಳನಿಲುವು |
| [Everyday Words](everyday) | Single-word requests and short copy | awesome → ಬೆರಗಿನ, floss → ಹಲ್ಲುನೂಲು, port → ರೇವು, Rajyotsava wishes → ಕನ್ನಡ ನಾಡಸುಗ್ಗಿಯ ಹಾರೈಕೆಗಳು |
