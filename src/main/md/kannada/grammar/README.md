# ಕನ್ನಡ Verb Paradigms

Verb paradigm tables for three representative Kannada verbs, following
D. N. Shankara Bhat — *ಕನ್ನಡ ಬರಹದ ಸೊಲ್ಲರಿಮೆ* Vol 2, §5.1.1.

Each entry has a plain text version (this site) and a **styled illustrated version**
with Noto Kannada fonts and colour-coded tense rows.

## Tense, aspect and mood

[Tense, Aspect, Mood: DNS Bhat vs Chomsky and Other Frameworks](./tense-aspect-mood) sets Bhat's *The Prominence of Tense, Aspect and Mood* against generative grammar (Chomsky, Pollock, Cinque, Ritter–Wiltschko) and the typologists (Reichenbach, Comrie, Dahl, Bybee). It explains why Kannada counts as tense-prominent, using the paradigms above, and has case studies on Japanese and Sanskrit.
