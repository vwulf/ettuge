# MiniLean

A small type checker for a dependent type theory, written in Lean 4 after the
book [MiniLean4](https://learn.h5i.dev/). It proves the sum formula
2 · (1 + 2 + ⋯ + n) = n(n + 1) from an empty environment, with no axioms.

Companion to the articles
[MiniLean: The No Magic Proof in a Kernel You Can Read](../../md/pl/minilean.md) and
[No Magic](../../md/pl/lean-no-magic.md).

## Build

```sh
cd src/main/lean/minilean
nix develop      # or install elan yourself
lake build
```

`lake build` runs MiniLean's kernel on every declaration in `MiniLean/Prelude.lean`
and `MiniLean/Rejections.lean`. If MiniLean rejects a declaration that should be
accepted, or accepts one that should be rejected, the build fails.

## Literate pages

The library renders as a literate website, **No Magic, implemented**: a
walkthrough of the sum formula in nine stages (`MiniLean/Walkthrough/`), then the
source of every module. The site's deploy workflow publishes it at
<https://vwulf.github.io/ettuge/FP/minilean-literate/>. To build it locally:

```sh
lake query :literateHtml   # prints the output directory
```

Verso is a documentation-only dependency. `literate.toml` sets the landing page,
the order, and which `#mini_…` commands show their output.

Every output the pages show is pinned in `MiniLean/Checks.lean`, which is
generated by `scripts/gen_checks.py`. After changing a page, run
`python3 scripts/gen_checks.py`, review the diff, and rebuild.

## Layout

| File | Lines | Trusted? | Purpose |
| --- | --- | --- | --- |
| `MiniLean/Level.lean` | 110 | yes | universe levels, level equality |
| `MiniLean/Expr.lean` | 180 | yes | terms, substitution, abstraction, printing |
| `MiniLean/Env.lean` | 62 | yes | the environment of declarations |
| `MiniLean/Kernel.lean` | 393 | yes | `whnf` (β δ ι), `isDefEq`, `infer`, declarations, recursor generation |
| `MiniLean/Surface.lean` | 68 | no | name resolution |
| `MiniLean/Tactic.lean` | 240 | no | `intro`, `exact`, `refl`, `show`, `induction`, `rw` |
| `MiniLean/DSL.lean` | 338 | no | the `mini_…` commands |
| `MiniLean/Prelude.lean` | 169 | — | `Nat`, `Eq`, `add`, `mul`, `sumTo`, nine lemmas, the theorem |
| `MiniLean/Rejections.lean` | 72 | — | wrong declarations the kernel must refuse |
| `MiniLean/Walkthrough/` | — | — | the companion: one page per stage |
| `MiniLean/Explain.lean` | 343 | no | display commands that show one pipeline stage at a time (`#mini_tactics`, `#mini_kernel`, …) |
| `MiniLean/StepByStep.lean` | — | — | one proof, `zero_add`, followed through every stage |
| `MiniLean/Checks.lean` | — | — | every shown output, pinned (generated) |

Only the first four files are trusted. Everything else produces terms that the
kernel checks.

## The DSL

```lean
mini_inductive Nat : Type where
  | zero : Nat
  | succ : Nat → Nat

mini_def add (m n : Nat) : Nat :=
  Nat.rec.{1} (λ (k : Nat) => Nat) m (λ (k ih : Nat) => succ ih) n

mini_theorem zero_add (n : Nat) : NatEq (add zero n) n := by
  induction n
  · refl
  · intro k ih
    show NatEq (succ (add zero k)) (succ k)
    rw [ih]
```

Commands: `mini_inductive`, `mini_def`, `mini_theorem`, `mini_open`, `#mini_check`,
`#mini_reduce`, `#mini_print`, `#mini_trace` (each β/δ/ι step), `#mini_expr` (the
raw term), `#mini_verdict`. MiniLean declarations are saved with their Lean module,
so a file that imports `MiniLean.Prelude` can use everything declared there.
